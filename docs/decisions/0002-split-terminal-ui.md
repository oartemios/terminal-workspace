# 0002 — оформление и две области TUI

Статус: локальное обратимое решение реализации по предоставленному визуальному референсу.

При размере от 90×16 рендер использует две области: 44% для списка объектов, остальное для контекста и результатов. Размеры и RGB-палитра — defaults реализации, не продуктовый контракт. На меньшем терминале сохраняется компактный рендер. Используются Unicode-рамки и ANSI true color, без новых зависимостей и иконок действий.

При высоте от 24 строк верхние вкладки и группы помещаются в отдельные панели, объекты занимают одну строку с символом типа перед названием, без разделителей между элементами, результаты имеют отдельный заголовок/метаданные и номера строк, а подсказки клавиш — рамку и цветовое выделение. При меньшей высоте двухколоночный вид остаётся плотным. Высота страницы списка и результата различается: PageUp/PageDown считают объекты списка и строки результата соответственно. Заголовок результата использует аргумент выполненной команды, который может отличаться от текущего выделения.

Результаты команд, контекстные действия, палитра и справка отображаются справа; список остаётся видимым. Esc возвращает режим навигации. Предпросмотр выполняется явно через существующий CommandInvocation: рендер не обращается к файловой системе и не запускает команды. Сведения о выбранном Item используют его публичные title, kind и id, без Files-логики в Core. Другие плагины используют свои группы и объекты в той же компоновке. Контракты команд, действий и навигации не изменены.

Количество строк для прокрутки обновляется вместе с шириной и высотой терминала. Проверки покрывают границы кадра, Unicode, управляющие символы в результате, видимость списка вместе с output, прокрутку и реальный PTY с переключением между компактным и широким режимами. Это не полная реализация экрана Writing из референса: Writing, редактирование текста, прогресс глав и связи предметных объектов остаются задачами соответствующего плагина.

Символ типа задаёт плагин через необязательный `Plugin::item_icon`: Files использует ▸ для каталогов и ▤ для файлов, default — •. Core не интерпретирует доменные kinds. Символы имеют ширину одной терминальной ячейки; управляющие, широкие символы и panic заменяются на •. UI кеширует символы при загрузке представления, рендер не вызывает плагин. Nerd Fonts не требуются. Текст kind остаётся в сведениях о выбранном объекте.
