# 0001 — терминальный интерфейс первого рабочего среза

Статус: локальное решение реализации, обратимое. Продуктовые требования не предписывают конкретные crates или раскладку клавиш.

## Выбор

Используем `console 0.15.7` для ширины Unicode и типов клавиш, `libc 0.2.167` — для Unix termios, poll и размера терминала. Эти версии доступны локально, собираются offline с Rust 1.74 и покрывают целевые macOS/Linux. ANSI-рендер пока мал: вкладки, список, statusline и рабочая область для действий, палитры и Blocks. При усложнении layout можно заменить этот слой библиотекой TUI.

`Ui` отдельно хранит фокус, выбор, фильтр и режим. Оно принимает события клавиш и выдаёт ограниченный размером терминала кадр; тесты не требуют реального терминала. Рабочая область не содержит Files-логики. Все четыре способа вызова операций плагина создают `CommandInvocation` и используют `App::invoke`.

## Поведение

Список кэшируется в состоянии интерфейса; навигация не перечитывает каталог. Открытие группы и refresh пока синхронные. Ввод опрашивается с периодом 100 ms для обнаружения изменения размера; поступившая клавиша обрабатывается сразу. Последовательности `f p`, `f s` и остальные defaults записаны в README и справке.

Терминальный guard использует alternate screen, скрывает курсор и восстанавливает termios, курсор и основной экран при штатном выходе, ошибке ввода и Rust unwinding. Ctrl-C в raw mode обрабатывается как клавиша выхода. Принудительное завершение процесса внешним сигналом не покрывается этим guard.

Содержимое плагина очищается от управляющих символов перед рендером, строки обрезаются по экранной ширине Unicode. Ошибка выполнения сохраняется в statusline и не закрывает сессию.

## Оставшиеся ограничения

Этот этап не задаёт внешний ABI, sandbox, persistence или async runtime. Для сетевых плагинов потребуется неблокирующая загрузка и состояние доступности. Целевые показатели PRD требуют отдельного измерения; они не объявляются достигнутыми этой реализацией.
